# 🛒 Gestão de Produtos e Produtos Perecíveis em Java

Projeto desenvolvido para consolidar conceitos de Programação Orientada a Objetos (POO) e a manipulação moderna de datas em Java.

## 📌 Funcionalidades & Conceitos Aplicados
- **Herança e Polimorfismo:** Reuso de atributos/construtores da classe `Produto` na classe `ProdutoPerecivel` e sobrescrita do método `@Override toString()`.
- **Manipulação de Datas (`java.time`):** Uso do `LocalDate` para representação de datas de vencimento e `DateTimeFormatter` para exibição no padrão brasileiro (`dd/MM/yyyy`).
- **Encapsulamento e Coleções:** Organização dos atributos como `private`, expostos por `getters`/`setters`, e iteração de listas heterogêneas com `ArrayList`.

## 🛠️ Tecnologias Utilizadas
- **Java** (JDK 17+)
- **IDE:** NetBeans / VS Code / IntelliJ
